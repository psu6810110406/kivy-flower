# วิธีใส่รูปภาพของตัวเอง 🎨

ในการเปลี่ยนดอกไม้จากอิโมจิ (Emoji) เป็นภาพวาดของตัวเองหรือเพื่อนที่คุณวาดขึ้นมา ให้ทำตามขั้นตอนนี้ครับ:

1. นำไฟล์รูปภาพ (แนะนำเป็น `.png` พื้นหลังใส หรือ `.jpg`) มาใส่ในโฟลเดอร์ `assets` นี้
2. ตั้งชื่อไฟล์รูปภาพให้ตรงกับที่ผมตั้งไว้ในโค้ด `flower.py` (หรือจะไปแก้ชื่อไฟล์ในโค้ดให้ตรงกับรูปก็ได้ครับ)

**ตัวอย่างชื่อไฟล์รูปภาพปัจจุบันที่เตรียมไว้ให้ (ต่อ 1 ต้นไม้):**
- **ทานตะวัน:** `seed.png` (เมล็ด), `sprout_sunflower.png` (ต้นอ่อน), `sunflower.png` (โตเต็มวัย)
- **กุหลาบ:** `seed.png`, `sprout_rose.png`, `rose.png`
- **ทิวลิป:** `seed.png`, `sprout_tulip.png`, `tulip.png`
...และอื่นๆ ดูได้ในโค้ด `flower.py` ตัวแปร `GAME_DATA` ด้านบนๆ ครับ

**หมายเหตุ:** วันไหนที่ไม่มีรูปภาพ ระบบจะฉลาดพอที่จะแสดงผลเป็น "อิโมจิ" ตามเดิมครับ ดังนั้นไม่ต้องกลัวว่าถ้าใส่รูปไม่ครบแล้วเกมจะพัง 🚀
